# 🏡 Simple Linear Regression from Scratch: House Price vs Area

A first machine learning notebook that predicts house prices from square footage using simple linear regression, built on a small synthetic dataset with a known relationship between area and price plus random noise.

## Workflow

1. Create a dataset with an area-to-price relationship and some random variation
2. Visualise the data and confirm the upward trend with a scatter plot
3. Separate independent (area) and dependent (price) variables
4. Split the data into training and testing sets
5. Create and train the scikit-learn LinearRegression model
6. Predict on the test set and evaluate with R-squared

## Tech Stack

Python, Pandas, NumPy, Matplotlib, scikit-learn, Jupyter Notebook

## Repository Contents

- `Building a Simple Linear Regression Model.ipynb`: the full notebook

## How to Run

1. Clone the repository
2. Install the libraries: `pip install pandas numpy matplotlib scikit-learn jupyter`
3. Run the cells in order with `jupyter notebook`. No external dataset is needed.
